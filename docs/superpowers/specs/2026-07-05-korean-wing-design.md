# Ⅳ관 "한국의 방" 추가 — 조선 회화 4점 신규 기법 · 설계 스펙

- 날짜: 2026-07-05
- 상태: 승인됨
- 선행 스펙: 2026-07-04-masterpieces-reborn-design.md (전시 본체),
  2026-07-04-bull-puppet-swap-design.md (12번 황소 교체 — 함께 구현·배포)

## 1. 목적

전시에 네 번째 전시관 **Ⅳ관 "한국의 방"**을 신설하고 조선 회화 4점(13~16번)을
**기존 12작품과 겹치지 않는 신규 기법**으로 추가한다. 12번 황소 교체와 묶어
하나의 구현 계획으로 완료 후 한 번에 재배포한다.

## 2. 저작권 근거

- 후보에서 제외: 박수근(1965 작고)·김환기(1974)·이상범(1972) 등 — 1963년 이후
  작고 작가는 사후 70년 보호(2013 연장법)로 아직 보호 중.
- 채택된 조선 회화 4점(작가 작고 1447~1813년대)은 **전 세계적으로 완전한
  퍼블릭 도메인** — 원작 이미지 번들 가능.

## 3. 구조 변경

- `js/data.js` WINGS 추가:
  `{ id: "korea", index: "Ⅳ", name: "Korean Masters", sub: "한국의 방", accent: "#63b8a0" }`
- WORKS 13~16 추가 (아래 4장). 16작품/4관 — 관당 4점 대칭 유지.
- `index.html`: hero lead "열두 점 → 열여섯 점", "세 개의 전시관 → 네 개의
  전시관", hero__meta "12 WORKS→16 WORKS", "3 WINGS→4 WINGS",
  meta description의 작품 수 갱신. (황소 스펙의 콜로폰 문구 변경도 병행)
- `test/data.test.mjs` 수정: 전시관 3→4, 작품 12→16, 번호 01..16, 관당 4점.
  integrity 테스트는 data.js 기준 자동 추종.

## 4. 작품 정의 (data.js 항목 + 연출)

공통: 기존 모듈 계약(default export {init,tick,resize,dispose}, 모듈 내
리스너/rAF/타이머 금지, dt 누적, pointer 입력만, 함수 내부 오프스크린만 허용,
CSS px, asset null 시 절차적 폴백, reducedMotion 감쇠) 전부 적용.
