# 05번 After Monet — Impression, Sunrise 인상주의 리페인트 설계

- 날짜: 2026-07-10
- 대상: `js/pieces/05-impression-sunrise.js` (단일 파일 재작업)
- 배경: 사용자 피드백 — "인상주의 작품인데 인상주의 작가 풍의 느낌이 안 산다. 인상주의 느낌이 더 살아났으면 좋겠다."

## 문제 진단

현재 구현은 구도(안개 낀 르아브르 항구, 태양, 조각배, 반사)는 원작을 따르지만, 렌더링이
`createLinearGradient` 기반의 매끈한 면 채우기 + 깔끔한 사인파 밴드여서 벡터 일러스트처럼
읽힌다. 인상주의의 핵심 시각 언어인 **끊어진 붓터치(broken brushstrokes)**, **병치된 색의
진동(optical mixing)**, **거친 윤곽**이 부재한다. 또한 태양이 밝은 노랑인데, 원작의 태양은
회청록 안개와 보색 대비를 이루는 선명한 주황-버밀리언이며 이것이 그림의 정체성이다.

## 사용자 결정 사항 (2026-07-10 확정)

1. **적용 범위**: 전면 붓질 리페인트 — 하늘·안개·바다·반사 전부 붓터치로 재구성.
2. **태양 색**: 원작 주황-버밀리언으로 변경 (기존 "밝은 노랑" 요청을 대체하는 결정).

## 설계

### 1. 렌더링 구조 — 3층 레이어

| 레이어 | 페인트 시점 | 내용 |
|---|---|---|
| 하늘(오프스크린) | init/resize 시 1회 | 회청록 밑칠 + 짧은 붓터치 2,000~3,000개. 색상(회청·라벤더·연분홍·크림)·각도(수평 ±15°)·길이(10~40px)·투명도(0.1~0.4)를 터치마다 지터. 태양 주변에는 살구·복숭아 터치 가중. 안개는 radial gradient 블롭 대신 밝은 크림색 긴 터치 무리로, 느린 드리프트 유지. |
| 바다(오프스크린 밑칠 + 라이브 터치) | 밑칠 1회 + 매 프레임 | 청록~남색 붓터치 밑칠을 오프스크린에 페인트. 그 위에 라이브 터치 300~500개가 사인 위상 + `rippleField` 변위로 일렁임. 수평선 근처는 옅고 짧게, 전경은 짙고 길게. |
| 캔버스 질감 | 1회 생성, 매 프레임 오버레이 | 옅은 노이즈 그레인(알파 ~0.04)을 최상단에 얹어 캔버스 질감. |

### 2. 태양과 반사

- **태양 코어**: 버밀리언 주황(#f25c2a 계열). 완전한 원 1개 대신 살짝 어긋난 원형 daub
  2~3개를 겹쳐 붓으로 찍은 느낌. 반경 펄스 유지.
- **글로우**: 따뜻한 주황-호박색으로 재조정, 원작처럼 태양 원반이 "박혀 있는" 느낌이 살도록
  글로우 강도는 현재보다 과하지 않게.
- **클릭 인터랙션**: 방사형 광선(sunburst) + 코어 섬광 유지, 색만 주황-호박 계열로.
- **반사**: 가는 노란 점선 → 태양 아래로 내려오는 굵고 끊어진 주황 지그재그 daub 기둥
  (원작의 상징 요소). 명멸 + 리플 반응 유지.

### 3. 부속 요소

- **조각배**: 순검정(#0b1216) → 짙은 청자색 계열, 윤곽 살짝 거칠게(직선 대신 미세 지터).
  보빙 애니메이션 유지.
- **갈매기**: 유지, 짙은 회청으로.

### 4. 인터랙션 계약 (변경 없음)

- 클릭: 수면 리플 + 태양 방사 광선 + 코어 섬광.
- 드래그: 이동 누적 20px마다 소형 리플.
- 리플은 라이브 바다 터치와 반사 daub를 변위시킨다.

### 5. 성능·접근성

- 프레임당 비용: drawImage 2회 + 라이브 터치 ~400 + 반사/배/갈매기 → 현재 수준 이하 목표.
- 오프스크린 리페인트는 init/resize에서만.
- `reducedMotion`: 라이브 터치 수 절반, 일렁임·펄스 감폭(기존 `mo` 계수 체계 유지).
- export 계약(init/tick/resize/dispose)과 파일 위치 불변.

### 6. 팔레트 (원작 기준)

- 하늘: 회청 #6d7f8a, 청록회 #7a8d8f, 라벤더 #9b8fa0, 연분홍 #d9a08c, 크림 #d9cbb8
- 바다: 청록 #4a6670, 짙은 청록 #2e4a52, 남색 #253746, 따뜻한 반사 혼입
- 태양·반사: 버밀리언 #f25c2a, 주황 #e8622d, 밝은 주황 #ff7a3c
- 실루엣(배·갈매기): 짙은 청자 #1e2a38 계열 (순검정 금지)

### 7. 검증 — 원작 충실도 프로세스

1. 구현 에이전트는 원작 이미지를 직접 확보해 스크린샷과 나란히 3회 이상 대조
   (구도·색 대비·붓질 체감·화면 점유율).
2. 컨트롤러가 최종 스크린샷을 원작과 직접 대조.
3. 사용자에게 스크린샷을 먼저 보여 승인받은 뒤 배포(content-review-agent 85점 게이트 포함).
