2043년까지 보호(사후 70년)되고 미국에서도 1931년 이후 발표작이 보호 중이므로,
**특정 작품을 복제·재해석하지 않는 "스타일 오마주"**로 확정(사용자 선택).
스타일 자체는 저작권 보호 대상이 아니다. 원작 이미지 번들 없음, 특정 작품
구도 복제 금지.

## 3. 연출 계약

- **초상 생성**: 절차적 파라미터(면 분할 시드, 시점 혼합 비율, 이목구비 배치)로
  매번 다른 큐비즘 초상을 생성. 얼굴이 화면(뷰포트)을 가득 채움.
- **큐비즘 어법**: 정면 눈+측면 눈 공존, 옆모습 코, 이중 입, 면마다 다른 시점의
  음영. 종합적 큐비즘 팔레트(검정 굵은 윤곽 + 빨강·파랑·노랑·크림·회갈) +
  콜라주 질감 면(신문 스트라이프·도트·해칭 — 절차 패턴).
- **클릭 = 재조립**: 면들이 흩어졌다가 완전히 새로운 구성(새 시드)으로 재조립
  (애니메이션 전이, dt 기반). 매 클릭이 새로운 초상.
- **드래그 = 시점 비틀기**: 커서 주변 면들이 밀리며 기울고, 놓으면 새 균형으로
  스프링 안착.
- **유휴**: 면들이 느리게 호흡(미세 기울기·밝기), 시점 혼합 비율이 천천히 진동.
- reducedMotion: 재조립 전이·호흡 감쇠.

## 4. 모듈 계약·프로세스

- 기존 계약 동일: default export 4메서드, 금지 API 없음, dt 누적, pointer만,
  함수 내부 오프스크린만, CSS px, reducedMotion.
- 구현 에이전트는 큐비즘 초상의 **일반 어법**(시점 혼합, 면 분할, 팔레트)을 직접
  조사하되, **특정 피카소 작품의 구도·형상 복제 금지**. 비교 라운드는 "특정
  작품과 닮지 않았는지" 확인하는 **역방향 검증** 포함 2회 이상.
- 파일 변경: `js/pieces/12-bull-puppet.js` 삭제 → `js/pieces/12-cubist-faces.js`
  생성, data.js 12번 교체. (fetch-targets.sh 는 이미 12번 없음 — 무변경)
