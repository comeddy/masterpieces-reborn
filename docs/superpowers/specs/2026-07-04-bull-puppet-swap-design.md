# 작품 12 교체 — After Lee Jung-seob, Bull (황소 인형극) · 설계 스펙

- 날짜: 2026-07-04
- 상태: 승인됨
- 선행 스펙: 2026-07-04-masterpieces-reborn-design.md (전시 본체 — 배포 완료 상태)

## 1. 목적

Ⅲ관 12번 작품 "After Hiroshige — Sudden Shower"를 한국 근대미술 대표 화가
**이중섭(李仲燮, 1916–1956)**의 〈황소〉(c.1953) 기반 작품으로 교체한다.
컨셉: **"그림을 가위로 오려 막대에 붙인 종이 인형극"** — 오려낸 황소 조각들이
작은 프로시니엄 무대 위에서 관절 인형으로 공연한다.

## 2. 확정된 결정

| 항목 | 결정 |
|------|------|
| 원작 | 이중섭 〈황소〉 (c.1953) 단독 — 사용자가 "김중섭"으로 지칭했으나 검색 검증 후 이중섭으로 확인받음 |
| 컨셉 | 관절 인형 자동 공연 + 커서 조종 (접근 A) |
| 렌더 방식 | 100% 절차적 오리기 렌더 — 원작 이미지를 사이트에 번들하지 않음 |
| 제작 프로세스 | 구현 에이전트가 원작 이미지를 **직접 검색·수집**(스크래치패드 한정)하고, 자기 렌더와 원작을 **나란히 비교**하며 보정 (비교 라운드 최소 2회 기록) |
| 저작권 처리 | 이중섭 작품은 한국에서 저작권 만료(사후 50년, 2006년 만료 — 2013년 연장법 소급 없음). 미국 지위(URAA)가 애매하므로 원본 미번들·절차적 재해석만 사용. medium에 "public domain" 문구 사용 안 함 |

## 5. 작품 모듈 설계 — 12-bull-puppet.js

기존 모듈 계약 동일: default export `{init, tick, resize, dispose}`,
모듈 내 addEventListener/rAF/타이머 금지, dt 누적, pointer 입력만,
document는 함수 내부 오프스크린 캔버스 생성만 허용, CSS px 좌표.

### 무대 (init 시 오프스크린 베이크 가능)
- 프로시니엄 아치 + 양옆 붉은 커튼(주름 드리움) + 상단 발란스
- 각광(footlight) 3~5개 — 무대 앞쪽 아래에서 위로 은은한 글로우
- 배경막: 이중섭풍 주홍 노을 그라데이션 + 거친 붓결 텍스처
- 바닥: 나무 판자 무대

### 인형 (황소)
- 관절 체인: 몸통(루트) — 머리+목(1관절), 앞다리 2·뒷다리 2(각 상/하 2관절 또는
  1관절 — 구현 판단), 꼬리(1관절)
- 각 조각 렌더: 굵은 먹빛 윤곽 + 황토/주홍 붓질 절차 텍스처(방향성 스트로크)
  + **가위 단면**(흰 종이 테두리, 미세하게 삐뚤한 절단 라인) + 조각 아래로 가는
  나무 막대(무대 아래로 뻗음)
- 배경막에 부드러운 그림자(인형 뒤 오프셋 실루엣)

### 공연 (유휴 자동 루프, dt 기반)
걷기(다리 위상 보행 + 몸통 보빙) → 고개 젓기 → 울부짖기(머리 들어올림 + 온몸
들썩 + 각광 밝아짐) 시퀀스 반복, 각 동작 사이 자연스러운 이징 전환.

### 인터랙션
- 드래그: 커서에서 가장 가까운 막대(조각)를 잡아 조종 — 잡힌 조각은 커서 추종,
  나머지 관절은 스프링으로 자연 추종. 놓으면 공연 자세로 서서히 복귀
- 클릭: 돌진 — 무대를 가로질러 달림 + 커튼 들썩 + 무대 미세 진동
- reducedMotion: 들썩임·돌진·진동 감쇠

## 6. 제작 프로세스 (핵심 요구사항)

구현 에이전트에게 원작 자료를 직접 제공하지 않는다. 에이전트가:
1. 웹에서 이중섭 〈황소〉 원작 이미지를 직접 검색·수집 — **스크래치패드에만 저장**
   (저장소·assets·사이트 어디에도 포함 금지)
2. 자기 작품 스크린샷과 원작 이미지를 나란히 비교하며 실루엣(등선·뿔·다리 자세),
   팔레트(황토·주홍·먹빛), 붓질 방향을 보정
3. **비교 라운드 최소 2회**를 보고서에 기록 (라운드별: 발견한 차이 → 반영한 수정)
